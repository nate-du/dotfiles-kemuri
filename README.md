# Dotfiles
* Dotfiles (configuration settings) for a KDE Plasma installation
* Automated Ansible configuration of system packages 
* KDE Plasma font settings target a 1440p 27" screen

> [!TIP]
> For best results, apply dotfiles after EndeavourOS installation (ansible packages omit those already installed via EOS!)

See [INSTALLATION.md](INSTALLATION.md) for guided instructions.
